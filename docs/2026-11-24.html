Learn one thing

A key idea for the role

Germany's §14a rules for controllable devices

  • §14a is a German rule for controllable home devices like EV chargers and heat pumps.
  • Grid operators may limit these devices in a grid emergency, down to a minimum power.
  • In return, owners get reduced grid fees, which shapes how flexibility software earns.

→Germany is a likely early Axle market, so knowing §14a shows you understand its device rules.

Search: Germany §14a EnWG controllable consumption devices explained ↗
